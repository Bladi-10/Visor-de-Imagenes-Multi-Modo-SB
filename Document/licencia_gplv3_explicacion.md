# Explicación Detallada de la Licencia GNU GPLv3

## 1. ¿Qué es la Licencia GNU GPLv3?

La **GNU General Public License versión 3 (GPLv3)** es una licencia de software libre basada en el principio del **Copyleft Fuerte** (*Strong Copyleft*), desarrollada y mantenida por la *Free Software Foundation (FSF)*.

Su propósito fundamental no es solo dar acceso al código fuente, sino **preservar y defender la libertad de los usuarios para siempre**, asegurando que ninguna entidad o empresa pueda privatizar o cerrar el software.

---

## 2. ¿Qué SE PUEDE hacer con GPLv3? (Permisos)

- **Uso para Cualquier Propósito**: Puedes ejecutar el software libremente para uso personal, profesional, comercial, académico o gubernamental.
- **Acceso y Modificación del Código**: Tienes acceso completo al código fuente. Puedes auditarlo, adaptar la lógica, corregir errores o añadir nuevas funcionalidades según tus necesidades.
- **Distribución de Copias**: Puedes regalar, compartir o redistribuir copias del software (original o modificado) con quien desees.
- **Comercialización y Venta**: **Sí, se permite cobrar dinero.** Puedes cobrar por distribuir el software o por ofrecer servicios de soporte, instalación y consultoría. La única regla es que a las personas a las que les entregues el ejecutable también debes entregarles el código fuente bajo la misma licencia GPLv3.
- **Protección de Patentes Integrada**: Todo colaborador que publique código bajo GPLv3 otorga automáticamente a los usuarios una licencia de patentes explícita, gratuita y permanente sobre su contribución.

---

## 3. ¿Qué NO SE PUEDE hacer con GPLv3? (Restricciones y Copyleft)

- **NO puedes hacer el código cerrado o propietario**: Si modificas un programa bajo GPLv3 y **lo distribuyes a terceros**, estás obligado por ley a compartir todo el código fuente resultante bajo la misma licencia GPLv3.
- **NO puedes vincularlo (*linking*) con software privado**: Si integras una librería o módulo GPLv3 dentro de una aplicación comercial de código cerrado y la distribuyes, todo el programa combinado debe convertirse obligatoriamente en software libre GPLv3.
- **NO puedes realizar "Tivoización"**: GPLv3 incluye una cláusula anti-tivoización. Queda prohibido distribuir dispositivos de hardware (consolas, routers, TVs) con software GPLv3 en los que el fabricante use claves criptográficas para impedir que el usuario instale sus propias versiones modificadas del software en el dispositivo.
- **NO puedes demandar por patentes a los usuarios**: Si distribuyes software GPLv3 y luego inicias un litigio de patentes contra los usuarios de ese software, pierdes de inmediato todos los derechos de uso y distribución otorgados por la GPLv3.
- **NO puedes remover las atribuciones originales**: Debes conservar siempre los avisos de derechos de autor y las notas de la licencia original.

---

## 4. Cuadro Comparativo: Licencia MIT vs GNU GPLv3

| Criterio de Evaluación | Licencia MIT (Permisiva) | Licencia GNU GPLv3 (Copyleft) |
| :--- | :--- | :--- |
| **Protección del Código Libre** | No obliga a mantener el código libre. | **Obliga** a que todos los derivados sean libres. |
| **Reutilización Propietaria** | Las empresas pueden tomar el código y cerrarlo en un producto privado. | **Prohibido.** El código derivado jamás se puede cerrar. |
| **Distribución de Modificaciones** | Se pueden distribuir binarios modificados sin dar el código fuente. | **Obligatorio** entregar el código fuente completo a los usuarios. |
| **Cláusula Anti-Tivoización** | No posee. | **Sí posee.** Protege la libertad en dispositivos de hardware. |
| **Licencia Explícita de Patentes** | No explicita protección de patentes. | **Sí incluye** defensa explicita contra demandas de patentes. |
| **Filosofía Principal** | Libertad centrada en el **desarrollador** (haz lo que quieras). | Libertad centrada en el **usuario** (garantizar software libre perpetuo). |
